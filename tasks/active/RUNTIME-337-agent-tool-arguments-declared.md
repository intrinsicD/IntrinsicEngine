## Goal
- M2 target "100 % of MCP tools are generated" (`ARCH-020` row 3). Baseline (`RUNTIME-336`): 48
  tools, none whose schema is generated whole; most compose hand-written JSON fragments
  (`kEntityProperty`, `DomainProperty`, `LaneProperty`, `AttributeProperty`, inline literals).
- This slice adds the declaration mechanism and converts the 36 tools listed in Plan 3; the rest is
  listed with the reason (constraints JSON Schema expresses but `ConfigFieldSpec` does not, or
  deferred for scope), for the next slices.

## Plan
1. **Declared arguments** (agent internal header): `AgentArgument` = a `ConfigFieldSpec` (name,
   type, bounds, enum tokens, description) plus `Required` and an optional `Default`;
   `ArgumentsSchema(arguments)` builds the input schema from them with the existing section schema
   generator (`BuildSectionSchemaJson`, as `ParamsSchema` does), strips its document keys and adds
   `required`. One declaration each for the shared arguments: entity (UInt 1..UINT32_MAX), element
   domain (the `GeometryElementDomain` tokens), render lane (surface/edges/points), render attribute
   (the attribute table's tokens). Mappings stay faithful (B1): `UInt` always emits 0..UINT32_MAX,
   so an integer without a maximum (`property_values.offset`) is `Int` with `Min` 0; unrestricted
   strings and absent defaults stay so; `set_visibility` keeps its `bounds` lane.
2. **Registration**: `AddOperation` takes a `ToolSchema` (text, or generated by `ArgumentsSchema`,
   which alone sets `DeclaredArguments`, a new `AgentOperationSpec` flag, false by default). The
   flag means complete input-schema provenance (O1), not generated handlers or defaults applied by
   handlers; progress is reported as declared input schemas of all tools.
3. **Converted** (arguments fully expressible): `scene_entities`, `entity_properties`,
   `select_entity`, `import_file`, `save_scene`, `load_scene`, `show_property`,
   `attribute_bindings`, `vector_fields`, `vector_field` (envelope + its style table),
   `lane_style` (envelope + its style table), `set_visibility`, `history`, `undo`, `redo`,
   `config_sections`, `log`, `property_list`, `property_stats`, `property_values`, the K-Means and
   consolidation pairs, the registration pair (a required method enum), the mesh-operation aliases
   (operation enum and entity, B2), `config_schema`, `config_get`, `jobs_list`, `jobs_cancel`, and
   the no-argument operation tools (`preview_/run_point_sampling`, `preview_/run_keypoint_analysis`),
   as far as their schemas match exactly (step 4).
   Not converted, with the reason: `bind_attribute` (`const` and `oneOf`), `jobs_wait` (`oneOf`),
   `set_camera` (nested arrays and objects with their own required keys), `property_compare`
   (nested objects with required keys), `config_preview`/`config_apply` (payload
   `["object","string"]`), `run_/preview_operation` (`allOf` of `if/then` per operation). Deferred
   for scope, expressible today: `view_screenshot`, `view_capture`, `diagnostics_read`,
   `device_status` (they register in their own units without the agent helper header and omit
   `required`; next slice).
4. **No behaviour change, shown and kept (B3)**: a committed baseline,
   `tests/data/agent_declared_tool_schemas.json`, holds the hand-written schema of every converted
   tool as registered at `36dd1fc81` (dumped before any source change). The generated schema must
   equal it as JSON (key order aside), descriptions, `x-enum-names`, defaults and `required`
   included. Only rows a style table gains later are left out of the comparison (`vector_field`,
   `lane_style`); `DeclaredFieldContracts` checks those per row against the registered schema. A
   tool whose schema would differ stays hand-written in this slice.

## Tests (predictions as assertions)
- `AgentOperations.DeclaredSchemasEqualTheHandWrittenBaseline`: the flag is set exactly for the
  tools in the baseline, each generated schema equals its baseline, and the count is pinned (the
  progress measure; registration already refuses an unsupported schema).
- `AgentArgumentSchema.RegisteredDeclaredArgumentsKeepTheirRules` (B4), on the registered schemas:
  entity 0 and UINT32_MAX + 1 refused, 1 and UINT32_MAX accepted, missing required arguments
  refused, `property_values.offset` above UINT32_MAX accepted, unknown domain and operation tokens
  refused, `set_visibility` accepts `bounds`, `lane_style` does not.
- Refactoring: `AgentOperations.*`, `AgentArgumentSchema.*` (incl. the unknown-argument sweep over
  every tool), `DeclaredFieldContracts.*`, `SandboxAgentServer.*` pass before and after.
- Mutations of the declarations and the generator, each must turn a test red: the entity argument
  loses its minimum; `ArgumentsSchema` does not set the flag; `required` dropped; `offset` declared
  `UInt` (an added maximum).
