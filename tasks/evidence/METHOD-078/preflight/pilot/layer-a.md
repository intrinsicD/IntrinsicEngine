## Outputs and analysis code
Outputs are under `tasks/evidence/METHOD-078/runs/`; no previous outputs are overwritten.
Native JSON: status, termination, iteration counts, accepted-Nystrom count, sampled error,
seconds, RMS/max distance to the Auto reference (world units), RMS to synthetic truth, final
sigma² and scale. Binary positions accompany each complete run. The driver records the maximum completed-child
RSS seen so far (KiB); this cumulative peak bounds the largest configuration, not per-cell memory.
`NYSTROM_DIAG` logs normalized pre-E-step sigma², remembered threshold, every attempt's landmark
count, acceptance, sampled error (NaN means it returned before the error calculation),
non-positive/non-finite target/source intermediate rejection, and the cost-cap decision.

policy, sampled error, kernel counter, cumulative seconds. `CPD_STAGE` records stage boundaries.
The existing kernel counter is incomplete for early returns; it is not a timing proxy.
`traces`, `assessed`, and `report` in `diagnose.py` own parsing, comparisons and HTML generation.

The report includes raw logs, per-iteration curves, first cached-suppression markers, a stage timeline with marked boundaries and raw-log
links, before/after point views at the same axes, and the frozen verdict. BCPD's implemented
stopping objective is NLL: its reported prior contribution is zero. It is not a full VB ELBO.
`fixture-preview.txt` contains the first/last 64 points of source, target and truth, generated by
